# 📊 Análise de Vendas E-commerce — Olist

Projeto de análise de dados desenvolvido em **Power BI** utilizando dados públicos da Olist.

O objetivo foi transformar dados brutos de vendas em um dashboard interativo para acompanhar indicadores comerciais e facilitar a análise do desempenho do e-commerce.

## 📈 Principais indicadores

- Faturamento Total: **R$ 15,84 milhões**
- Total de Pedidos: **aproximadamente 99 mil**
- Ticket Médio: **R$ 159,36**
- Evolução mensal do faturamento
- Top 10 categorias por faturamento
- Faturamento por estado

## 🛠️ Ferramentas utilizadas

- Power BI
- Power Query
- DAX
- Modelagem de Dados
- Tratamento de Dados
- Análise de Dados

## 🔎 Tratamento e qualidade dos dados

Durante a análise, identifiquei registros incompletos no período final da base.

Para evitar que esses registros fossem interpretados como uma queda real no faturamento, o período principal da análise foi limitado até **31/08/2018**.

Também foram realizadas etapas de limpeza, padronização e tradução das categorias de produtos no Power Query.
